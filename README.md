# Online-Examination-System

# Project Overview
The **Online Examination System** is a console-based application built in Python 3 that administers a multiple-choice examination to students. The system displays questions one by one, validates user inputs, allows question skipping, and automatically evaluates the final score, percentage, and Pass/Fail status at the end of the exam.

------------------------------------------------------------------------------------------------------------------------------

# Objectives
- Implement a structured console-based quiz using Python lists and dictionaries.
- Enforce input validation so only valid options (`a`, `b`, `c`, `d`, or `s`) are accepted.
- Modularize code using functions for question retrieval, input validation, exam execution, and score calculation.
- Accurately compute exam metrics (Correct, Wrong, Skipped, Score, Percentage, and Result).

------------------------------------------------------------------------------------------------------------------------------

# Features
- **5 Multiple-Choice Questions (MCQs):** Each question carries 2 marks (Total = 10 marks).
- **Skip Functionality:** Students can enter `s` to skip any question without penalty.
- **Real-Time Input Validation:** Prompts the user again if an invalid choice (e.g., `e`, numbers, or symbols) is entered.
- **Automated Grading:** Calculates total marks and percentage, awarding a `Pass` status for scores of at least 40% (4/10 marks).

------------------------------------------------------------------------------------------------------------------------------

# Requirements
- **Language:** Python 3.x
- **External Libraries:** None (uses standard Python 3 built-in constructs)
- **Supporting Data Files:** None required (questions are stored in-memory as a list of dictionaries per project specifications).
